# v5.1.0 Beta 릴리스 노트

- 배포일: 2026-11-27
- 패키지 버전: 5.1.0

표준프레임워크 프로젝트가 표준프레임워크 아키텍처 가이드를 따르는지 점검하는 MCP 서버, eGovFrame Check(적용점검 MCP)의 최초 배포 버전입니다.

## 주요 내용

- 제공 도구: `egov_check_compliance` 1개 (`projectPath`, `exportResults`, `runtimeGeneration`)
- 빌드 파일 점검: 빌드 도구를 실행하지 않고 `pom.xml`, `build.gradle`, `build.gradle.kts` 를 읽어서 점검합니다.
  - 모듈별 실행환경 세대(3.x / 4.x / 5.x)와 버전
  - 필수 라이브러리 4종(`ptl-mvc`, `fdl-cmmn`, `fdl-logging`, `psl-dataaccess`)의 적용 여부와 모듈 간 버전 일관성
- Java 소스의 레이어별 점검: Controller, Service, DAO / Mapper
  - Controller: `@Controller` 사용, 요청 매핑 어노테이션, DAO 를 직접 주입받지 않는지
  - Service: `EgovAbstractServiceImpl` 상속, `@Service` 사용, Service 인터페이스 구현
  - DAO / Mapper: 구현 방식별 기반 클래스, Bean 등록, 실행환경 세대와의 정합
- 점검 결과 보고: 레이어별 준수율과 파일별 실패 사유
  - 실패 파일을 MCP `resource_link` 로 반환하여 클라이언트에서 바로 열 수 있습니다 (최대 100개).
  - 점검 결과 CSV 4종(Project, Controller, Service, DAO)을 내보낼 수 있습니다 (선택).
- 결정적 판정: 판정은 모두 서버 코드가 정해진 규칙에 따라 수행하므로, 같은 프로젝트는 항상 같은 결과를 얻습니다.
- 폐쇄망 지원: 실행에 필요한 의존 패키지가 배포 파일(tgz)에 함께 들어 있습니다.

## 요구 사항

- Node.js 18 이상 (Node.js 22 권장)
- 운영체제와 CPU 에 맞는 배포 파일을 사용합니다. 배포 파일마다 그 플랫폼용 ripgrep 실행 파일이 들어 있습니다.

## 설치와 등록

배포 파일은 압축을 풀지 않고 `npx` 로 실행하도록 AI 클라이언트에 등록합니다. 클라이언트별 등록 방법은 [설치와 MCP 클라이언트 등록 가이드](../setup/MCP_SETUP_GUIDE.md)에 있습니다.

```bash
npx -y --package=<tgz 파일의 절대 경로> egovframe-mcp-check
```
